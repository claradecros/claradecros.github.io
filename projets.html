Reporting d’analyse multivariée

Expertise menée pour l'État visant à créer un outil automatisé de suivi de la pauvreté en France, basé sur l'exploitation des données open-data de l'INSEE (période 1970-2021).

Analyse Statistique Globale

  • Analyse en Composantes Principales (ACP) : Réduction de la dimensionnalité pour identifier les corrélations structurelles sous-jacentes entre précarité, niveau d'éducation et typologie d'emploi.
  • Clustering (CAH) : Classification Ascendante Hiérarchique pour segmenter les départements français en groupes homogènes de vulnérabilité.

Développement R Shiny

  • Interface réactive : Programmation réactive d'une application web permettant de filtrer dynamiquement les analyses multivariées par région.
  • Cartographie interactive : Intégration de packages Leaflet/Plotly pour visualiser les grappes de pauvreté à l'échelle départementale.
